# Volume 9: User Manual

## 1. Introduction
This manual guides users in running and monitoring the BLE Indoor Positioning System.

## 2. System Requirements
* Python 3.10+
* ESP32 anchors flashed with the scanner firmware
* Main Tag (beacon)

## 3. Running the Dashboard
Run the following command from the root of the project to open the visual dashboard:
```bash
streamlit run ble-indoor-positioning/dashboard/app.py
```
This will open the tracking screen in your web browser.
